## 2024-05-24 - [Concurrent file processing over Sequential]
**Learning:** [In the frontend, when handling multiple file uploads simultaneously (like dragging and dropping multiple images into the uploader), processing them sequentially with a `for` loop that awaits each process is a massive performance bottleneck. The browser's main thread or worker threads spend a lot of time waiting for each I/O or heavy computation (like HEIC to JPEG conversion) to finish before even starting the next one. Using `Promise.all` allows these independent asynchronous operations to run concurrently.]
**Action:** [Always look for sequential `for...of` or traditional `for` loops that `await` asynchronous operations on independent items in an array. Refactor them to `Promise.all` with a `.map` whenever the order of completion doesn't strictly depend on the previous item's result.]
