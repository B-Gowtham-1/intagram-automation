## 2024-11-20 - [ImageCard List Re-rendering Optimization]
**Learning:** In React list rendering with complex items like `ImageCard`, passing inline functions or constantly re-created function references (like drag-and-drop handlers from `ImageGrid`) will defeat standard `React.memo()`. Using a custom `areEqual` comparator that ignores function changes is a dangerous anti-pattern that can lead to stale closures if the parent's functions capture state (e.g., the array order being modified).
**Action:** Optimize the *parent* component instead by using stable function references. Convert `useState` to `useRef` for transient state (like `draggedIdx`) that doesn't need to trigger re-renders, and wrap handlers in `useCallback`. This allows standard `React.memo` to safely prevent O(n) re-renders on list operations without risking stale closure bugs.
