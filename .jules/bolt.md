## 2024-03-24 - Drag and Drop State causing Unnecessary List Rerenders
**Learning:** Using `useState` to track the currently dragged item index (`draggedIdx`) in a list component (like `ImageGrid`) triggers a full re-render of the list and all its children on every drag start and drop event. In components rendering multiple complex children (like images/videos in `ImageCard`), this causes O(N) re-renders, visibly impacting performance and responsiveness.
**Action:** When implementing drag-and-drop or similar ephemeral tracking that doesn't need to be reflected in the UI immediately during the action, use `useRef` to store the value instead of `useState`. Additionally, pair this with `React.memo` on the list items (`ImageCard`) and stable function references (`useCallback`) to completely prevent unnecessary renders.
