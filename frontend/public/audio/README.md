# Audio Files Directory

Place your audio files in this directory:
- `welcome.mp3` or `welcome.wav` : Audio/song played during the 3D Welcome sequence.
- `login.mp3` or `login.wav`     : Sound effect played immediately upon clicking login.

The application automatically checks for `/audio/welcome.mp3` (or `/audio/login.mp3`), with an elegant synthesized Web Audio fallback if the file is not yet placed!
